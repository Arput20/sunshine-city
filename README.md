# Sunshine City

Sunshine City is an open-world crime game in the browser: featuring a living city, traffic, police chases, missions, and a minimap.

## Controls
- **WASD**: Move / Drive
- **Mouse**: Aim
- **E**: Steal car
- **Esc**: Pause

## Running the Game
Run `python3 -m http.server` in the `game/` directory, then open `index.html`.
