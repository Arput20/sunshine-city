# Sunshine City

Sunshine City is an open-world crime game built in HTML5 canvas featuring high-octane driving, tactical combat, and dynamic city life.

## Features
- **Living Open-World City**: Dynamic day/night cycle, neon lighting, pedestrian crowds, and animated traffic.
- **4 Mission Types**: Beachside delivery, syndicate car chases, sunset time trial races, and VIP convoy escorts.
- **Wanted Star System & Police AI**: Escalate up to 5 wanted stars with aggressive cruiser AI and roadblocks.
- **Advanced HUD & Minimap**: Real-time minimap with blips, cash tracker, wanted meter, and mission objectives.
- **Juicy FX & Polish**: Screen shake on collisions, dynamic particle smoke, skid marks, and immersive audio cues.

## Controls
- **WASD / Arrows**: Move / Drive vehicle
- **Mouse**: Aim and shoot weapon
- **E**: Enter / exit vehicle
- **M**: Toggle mission list
- **P / Esc**: Pause game
- **F3**: Toggle debug FPS & statistics

## Running the Game
Run a local static file server in the `game/` directory:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
